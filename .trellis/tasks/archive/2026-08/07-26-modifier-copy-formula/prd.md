# Modifier-key copy formula body — 按住 Cmd 双击/拖动直接复制公式源码

## 概述

公式浏览器卡片当前的交互：单击复制 label、双击跳转源码行、拖拽插入 label。
增加修饰键（macOS Cmd / 其他平台 Ctrl）变体：按住修饰键时，双击直接复制
**公式源码（body）** 到剪贴板，拖拽把公式源码（而非 label）插入编辑器。

## 需求

### R1: 修饰键 + 双击

- 按住 Cmd（macOS）/ Ctrl（Windows/Linux）双击公式卡片 → 复制公式完整源码到剪贴板
- 不按修饰键的双击行为不变（跳转到源码行）

### R2: 修饰键 + 拖拽

- 按住修饰键拖出公式卡片 → `dataTransfer` 放入公式源码，拖入编辑器即插入源码
- 不按修饰键的拖拽行为不变（插入 label）

### R3: 可发现性

- 卡片 tooltip 补充说明修饰键用法
- 复制源码成功后沿用现有 `showInformationMessage` 提示风格

## 非需求

- 不改变单击复制 label 的行为
- 修饰键复制/插入源码同样计入 Recently Used（与普通操作一致）
- 不涉及移动端/无修饰键环境

## 验收标准

1. ✅ Cmd+双击卡片，剪贴板内容为公式源码（含 `\begin{...}...\end{...}`）
2. ✅ 普通双击仍跳转到对应源码行
3. ✅ Cmd+拖拽卡片到编辑器，插入公式源码；普通拖拽仍插入 label
4. ✅ 卡片 tooltip 提示修饰键用法
